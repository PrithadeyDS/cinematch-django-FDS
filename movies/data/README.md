# Kaggle Movie Dataset

This project bundles the CC0 `9000plus.csv` movie metadata file. The dataset includes release dates, titles, overviews, genres, popularity, vote counts, vote averages, original languages, and poster URLs. CineMatch imports the title, release year, overview, first listed genre, and rating. Ratings are divided by two to match the app's 0-5 scale. Mood labels are inferred from the full genre list using the rules in the import command; they are not labels supplied by the dataset.

Original Kaggle source: https://www.kaggle.com/datasets/disham993/9000-movies-dataset

Dataset card and CC0 license: https://huggingface.co/datasets/Pablinho/movies-dataset
